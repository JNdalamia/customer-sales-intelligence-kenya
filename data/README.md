# About the data folders

- `raw/synthetic/` has the full made-up retail records.
- `raw/public/` has the small KNBS CPI file taken from a public source.
- `sample/` has smaller copies of some fictional files to make them easier to open.
- `interim/` and `processed/` will be used for working and cleaned data later.

Keep the fictional sales data separate from the KNBS CPI file. The CPI file currently has only two months, so it is not enough for a 24-month comparison.
