# Project Charter

## Name
Customer and Sales Intelligence for a Kenyan Retailer

## Purpose
I will use fictional retail data to practise answering business questions about sales, stores, products, customers, promotions and next month's demand.

## Main users
Merchandising, regional operations, marketing, finance and stock-planning staff.

## Main outputs
- A checked set of fictional sales, transaction, customer, product, store and promotion files.
- Analysis of monthly sales and store/product performance.
- A simple view of repeat customers and promotion patterns.
- A next-month demand forecast compared with a basic estimate.
- A Power BI dashboard and a short report describing the results and limitations.

## How I will judge success
I will check that the files link together, key totals can be reproduced, transaction counts are not confused with product-line counts, and the forecast is tested against data that was not used to build it. I will label every generated business result as fictional.

## Scope for this milestone
The first milestone covers problem framing, a data inventory, the raw generated business data and one documented Kenyan public data source. The public CPI extract currently has only two months, so a full CPI analysis is not included yet.

## Tools
I plan to use Python/pandas, PostgreSQL, Power BI, Jupyter and Git/GitHub. I will use simple methods first and add more advanced techniques only when I understand why they are needed.
